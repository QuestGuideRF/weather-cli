# WeatherCLI 🌤️

Консольное приложение для получения информации о погоде через OpenWeatherMap API.

## Возможности

- ✅ Получение текущей погоды для любого города
- ✅ Прогноз погоды на ближайшие 24 часа
- ✅ Поддержка разных единиц измерения (Цельсий, Фаренгейт, Кельвин)
- ✅ Красивое форматирование вывода с эмодзи
- ✅ Локализация на русском языке
- ✅ Обработка ошибок и валидация входных данных

## Установка

1. Убедитесь, что у вас установлен Python 3.6+
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Быстрые примеры

### Для Москвы
```bash
# Текущая погода
python weather_cli.py Moscow

# Прогноз на 24 часа
python weather_cli.py Moscow --forecast

# В градусах Фаренгейта
python weather_cli.py Moscow --units imperial
```

## Использование

### Текущая погода
```bash
# Для Москвы
python weather_cli.py Moscow

# Для Санкт-Петербурга
python weather_cli.py "Saint Petersburg"

# Для других городов
python weather_cli.py London
python weather_cli.py "New York"
```

### Прогноз погоды
```bash
# Для Москвы
python weather_cli.py Moscow --forecast

# Для Санкт-Петербурга
python weather_cli.py "Saint Petersburg" --forecast

# Для других городов
python weather_cli.py "New York" -f
```

### Различные единицы измерения
```bash
# Для Москвы
python weather_cli.py Moscow --units metric     # Цельсий (по умолчанию)
python weather_cli.py Moscow --units imperial   # Фаренгейт
python weather_cli.py Moscow --units kelvin     # Кельвин
```

## API ключ

Приложение использует встроенный API ключ OpenWeatherMap. Если вы хотите использовать свой ключ:

```bash
python weather_cli.py Moscow --api-key YOUR_API_KEY
```

## Обработка ошибок

Приложение корректно обрабатывает различные ошибки:
- Неверное название города
- Проблемы с сетевым соединением
- Недоступность API
- Неверный API ключ
- Прерывание пользователем (Ctrl+C)

## Технические детали

- **Язык**: Python 3.6+
- **API**: OpenWeatherMap API v2.5
- **Зависимости**: requests
- **Кодировка**: UTF-8 с поддержкой эмодзи
- **Локализация**: русский язык для описания погоды
